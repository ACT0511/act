# AI 輔助互動式影像處理與人臉分析工具

期中專題:使用 Python 與 Streamlit 製作的影像處理工具。

## 功能
1. 影像載入與屬性顯示(PNG / JPG / BMP)
2. 色彩空間轉換(RGB / Grayscale / HSV / YUV)與直方圖
3. 自訂卷積核濾波(3×3、5×5、7×7…)與 PSNR 計算
4. 人臉偵測(Haar Cascade),顯示邊界框與信心度

## 本機執行
    pip install -r requirements.txt
    streamlit run app.py
